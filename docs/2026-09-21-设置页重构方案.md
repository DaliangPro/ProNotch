## 一、诊断（简）

1. **同一件事拆在两页，靠说明文字互相指路**：时区在功能组件页、时间槽位在通用页；天气卡在功能组件页、天气槽位在通用页。全文件 21 段灰色说明文字，多数在解释「这个在另一页」。
2. **Agent 页四家出现三遍**：监控开关、完成提醒勾选、颜色行各一遍；`glowEnabled` 总开关重开会把所有家的钩子全装回，按家取舍一次关开就丢。
3. **两个 API 编辑器长得像用法不同**：闪问要点「保存」，翻译即时生效；「名称」一个在卡内一个单独成卡；「检测」对「测试」；闪问「模型」输入框与「模型列表」两处都能定当前模型。
4. **命名与内容不符**：「快捷剪切板」页内全写「剪贴板」，一半是话术；「超级截图」九成是翻译配置；「音量与亮度」不是组件卡却在功能组件页。
5. **视觉词汇太多**：粉色开关、青色胶囊、灰底按钮、红底按钮、下拉框、状态圆点、勾选框、色块同页并存，卡片描边加分割线，几乎每行一句副标题。
6. **窗口 660×540 不可缩放**，超级截图页实高约两个窗口；侧栏无图标。
7. **权限不可见**：辅助功能、定位、屏幕录制三处要么一句灰字要么没有；屏幕录制是截图最常见故障点。

顺带发现（另开任务）：两侧功能区只有 Claude Code / Codex 槽位，Grok / Kimi 没有（`NotchSlot` 写死）；时钟城市网格离屏快照空白疑为 LazyVGrid 离屏不绘制。快捷键无冲突检测——并入本轮。

1. 每家菜单栏露出开关放在菜单栏面板各家详情页底部，不进设置页。
2. 快捷键跟功能走。
3. 本地 Agent 只列扫描发现的家；已勾选但已卸载的保留关闭入口。
4. 剪贴板「关＝停记录保留历史」，清空独立。
5. 面板页面随内容自动显隐（组件页三卡全关已会隐藏，核实过）。
6. ~~翻译与闪问接口清单各存各的~~ → 2026-09-22 大梁老师改口：两边共用一个接口池，一边配了另一边直接选。翻译的多套存档首启并入闪问接口池（ChatStore.mergeTranslateEndpoints，Key 沿用原钥匙串账号不搬），翻译只记「跟闪问」或池里某套的 id。翻译「共用闪问接口」默认开（核实过）。

## 三、设计语言（最终）

**五条规则**

1. 选择控件只留一种：单选用分段控件，多选用选片，长列表用下拉；胶囊与下拉两套颜色废除。**点亮即在用**：选片、磁贴都靠亮暗表示状态，不加对勾、不加外框。
2. 副标题只留会改变决定的（如「关闭后停止监听，已存历史保留」）；卡片下方独立说明段落全删。
3. 按钮只用文字：白色中等字重为操作（重新扫描、编辑、自定义、去授权），红色文字为破坏性（清空…、删除这套接口）；实心按钮只在弹层的「完成」。
4. 卡片无描边，无状态圆点：状态直接写「已授权」「未授权 · 去授权」。
5. 深层内容折进二级或条件显示：城市网格→一行摘要＋「编辑」；天气预览→「预览 ▾」；颜色→四个小圆点＋「自定义」；光晕外观三行滑块只在选「四周光晕」时出现；时区只在选「时间」时出现；权限警告只在未授权时出现。

**四种非清单表达**

| 表达 | 用在 | 替代了什么 |
|---|---|---|
| 刘海示意图：一条黑色屏幕带，中间刘海，两侧槽位就是下拉 | 刘海页顶部 | 两行各六格的槽位选择 |
| 磁贴：并列的同类项做成一排方块，只有图标/品牌点＋名字，点亮即启用，不嵌卡片、不加对勾、不写活跃天数 | 刘海页组件区（三张卡）、Agent 页本地 Agent（四家一排） | 三行 / 四行开关 |
| 列表＋弹层：接口配置列成一行一套，点「编辑」开弹层 | AI 闪问接口区、翻译接口下拉里的「新建」 | 页内平铺的名称/地址/Key/模型编辑卡＋胶囊切换条 |
| 总开关＋二选一分段＋条件行：开关决定要不要，分段决定哪种，只展开选中那种的细节 | Agent 完成提醒 | 光晕与弹窗设置同页并列 |

**文案**：行标签用最短的名词（快捷键 / 引擎 / 接口 / 时区 / 方式 / 哪些家），页面标题和小节标题已给上下文，不重复；副标题只剩三处（记录剪贴板、哪些家、权限对应功能）。

**配色**：直接取 Claude 桌面端深色主题的变量（从 /Applications/Claude.app 的 app.asar 里读出的 HSL 值换算，大梁老师 2026-09-22 定「参考 Claude Code 桌面端」）：

| 用途 | Claude 变量 | 色值 |
|---|---|---|
| 窗口底 | bg-100 | #262624 |
| 侧栏 | bg-200 | #1F1E1D |
| 卡片 / 弹层 | bg-000 | #30302E |
| 刘海示意带 | bg-300 | #141413 |
| 分割线 | 自定，比卡片亮一档 | #3D3C39 |
| 正文 / 操作文字 | text-000 | #FAF9F5 |
| 次级文字 | text-200 | #C2C0B6 |
| 说明文字 | text-400 | #9C9A92 |
| 强调（开关、当前项、弹层主按钮） | accent-brand | #D97757 |
| 破坏性 / 错误 | danger-100 | #DD5353 |
| 连接正常 | success-100 | #65BB30 |

暖灰不是冷灰。Claude 原值色相 60 度（红 = 绿 > 蓝），2026-09-22 实机点验大梁老师觉得发绿，色相挪到 30 度、明度不变：窗口底 #282624、侧栏 #211E1C、卡片 #33302E、最深 #161413、分割线 #3F3B38、次级文字 #C4BFB8、说明文字 #9E9A94（表里是 Claude 原值，代码以 SettingsTheme 为准）。开关从粉色换成 Claude 的陶土橙，与整体一致。磁贴、选片、分段控件仍用白色百分比叠底，自动带上暖调。

**规格**：窗口 700 宽、默认 620 高、可缩放记住尺寸；说明文字 12pt、白 60%；行高 44，卡片圆角 10；侧栏 176 宽带 SF Symbol 图标。

## 四、六页结构（最终）

侧栏顺序：通用 → 刘海 → 超级截图 → 剪贴板与话术 → AI 闪问 → Agent。

### 通用（`gearshape`）
- 开机自动启动
- 软件：ProNotch 版本 · 软件更新（已是最新 / 检查更新）· 项目主页
- 权限：辅助功能（音量与亮度提示）· 定位（天气）· 屏幕录制（超级截图）；已授权写字，未授权红字＋「去授权」

### 刘海（`macbook`）
- 刘海卡：真实预览（假菜单栏 + 黑色胶囊 + 两侧按真实样式渲染内存环 / 天气 / 时钟；2026-09-22 点验后由抽象示意图改成这个）· 左侧 / 右侧 [关闭 | 内存 | 天气 | 时间]（Claude Code / Codex 精灵槽位同日去掉）· 时区（条件）· 全屏时隐藏 · 显示在 [全部屏幕 | 仅主屏 | 仅副屏]
- 组件页：内存卡 / 世界时钟 / 天气卡三张磁贴（独立一排，不嵌卡）· 下方一张卡：世界时钟城市（摘要＋编辑，条件）· 恶劣天气预警（开关＋「预览 ▾」）· 预警类型选片（条件）
- 音量与亮度：按键时在刘海显示 [音量] [亮度]

### 超级截图（`camera.viewfinder`）
- 截图：快捷键 · 权限警告行（仅未授权时）
- 翻译：引擎 [系统翻译 | AI 模型] · 翻译成 ▾ · 接口 ▾（同闪问 / 接口池里任一套 / 新建…，与闪问页同一个池子）· 深度思考 · 并行加速 · 提示词（默认 / 编辑）
- 选「系统翻译」时翻译接口行换成「语言包 · 下载…」

### 剪贴板与话术（`doc.on.clipboard`）
- 剪贴板：记录剪贴板（副标题：关闭后不再记录，已有历史保留）· 保留条数 ▾ · 快捷键 · 历史记录 → 清空…（红字）
- 常用话术（标题右「新增」）：一行一条，标题＋预览，悬停出编辑/删除

### AI 闪问（`bubble.left.and.text.bubble.right`）
- 快捷键
- 接口（标题右「新增」）：一行一套，圆点定当前，名字＋域名，右侧状态＋「编辑」开弹层
- 对话：模型 ▾ · 深度思考
- 联网搜索：引擎 [DuckDuckGo | Tavily | Brave | 博查] · Key 行（条件，右侧「测试」）
- 页上没有「保存」按钮

### Agent（`cpu`）
- 本地 Agent（标题右「重新扫描」）：四家一排磁贴，只有品牌点＋名字，点亮即监控，不嵌卡、不加对勾、不写活跃天数（大梁老师 2026-09-21 定）；下一行灰字列其他已发现工具；未点亮的家不出现在「哪些家」选片里
- 完成提醒：完成时提醒（开关）· 方式 [四周光晕 | 顶部弹窗] · 呼吸周期 / 强度 / 厚度三行滑块（仅光晕）· 哪些家（选片，副标题「会写入该 Agent 的钩子配置」；失败行内红字）· 颜色（四点＋自定义）
- 额度：菜单栏显示额度

### 接口编辑弹层（闪问与翻译共用）
名称 · API 地址 · API Key · 模型列表（获取模型 / 勾选即当前 / 添加）· 测试连接 · 删除这套接口 · 取消 / 完成。完成即生效，无草稿。

## 五、交互规范

- **完成提醒**：删 `glowEnabled` 语义中的「重开全装回」。新增 `alertAgents`（勾选集，持久化）；钩子安装条件 = 任务完成时提醒开 ∧ 该家 ∈ enabledAgents ∧ 该家 ∈ alertAgents。总开关关只移除钩子，勾选集保留。刘海面板「Agent 提醒」按钮就是这个总开关。老用户迁移：`alertAgents` 首启取当前已装钩子的家。
- **钩子写入**：副标题写明会写该 Agent 配置；`setInstalled` 失败勾选保持原状、行内红字给原因。
- **监控关掉**：该家从「提醒哪些家」选片里消失（不是灰显）。
- **接口即时生效**：弹层「完成」即写入；页上模型下拉、深度思考切换即生效；ChatStore 的 draft→save 路径改直写。
- **翻译接口下拉**：选项 = 「同闪问 · <闪问当前接口名>」＋ 翻译专用各套 ＋「新建…」；选翻译专用套时行右多一个「编辑」。
- **条件行**：时区、城市、预警类型、Key 行、权限警告、光晕滑块均按状态显隐，不灰显。
- **权限**：通用页集中三项（AXIsProcessTrusted / CLLocationManager.authorizationStatus / CGPreflightScreenCaptureAccess）；功能页只在未授权时出警告行。
- **快捷键冲突**：录制时与别处相同则录入框下红字「已被超级截图使用」，不保存。
- **命名**：「剪切板」统一「剪贴板」（含面板顶部标签）；「系统提示」不用。未上线功能不出现占位行。
